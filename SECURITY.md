# Security Policy

If you believe you have found a security issue in this repository, please do not open a public issue with exploit details.

Instead, report the issue privately to the maintainers through the repository hosting platform or the project’s preferred private contact channel.

When reporting an issue, include:
- a description of the problem
- affected files or crates
- reproduction steps or proof of concept
- impact assessment, if known

The maintainers will review the report and determine the appropriate remediation and disclosure process.
